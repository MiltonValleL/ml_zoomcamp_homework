# Machine Learning Zoomcamp 2026 — Homeworks & Projects

This repository contains my homework submissions and hands-on projects for the
**Machine Learning Zoomcamp 2026**, a free 4-month course by
**Alexey Grigorev** (founder of [DataTalks.Club](https://datatalks.club) and author
of *Machine Learning Bookcamp*).

The course is project-based and covers the full ML lifecycle — from building your
first models to deploying them as production-ready web services. This repo tracks my
progress module by module and serves as part of my portfolio in my transition into
Machine Learning Engineering.

## About the course

- **Instructor:** Alexey Grigorev (DataTalks.Club)
- **Format:** Free, self-paced with a live cohort · weekly video lessons + graded homework
- **Cohort:** 2026 (started September 14, 2026) · ~4 months
- **Approach:** Learn by doing — every module ends with a practical assignment, and the
  course culminates in two deployed, real-world projects.

## What this repository contains

- **`module-XX/`** — One folder per module with my homework notebooks, scripts, and notes.
- **`midterm-project/`** — End-to-end project (data prep, EDA, model training,
  evaluation, and deployment) with its own README.
- **`capstone-project/`** — Final project demonstrating the complete workflow, deployed
  as a service.

## Course roadmap

1. **Introduction to Machine Learning** — ML vs. rule-based systems, CRISP-DM,
   reproducible environment setup.
2. **Regression** — Linear regression from scratch and with Scikit-Learn, feature
   engineering, regularization.
3. **Classification** — Logistic regression, categorical encoding, feature importance.
4. **Evaluation Metrics** — Accuracy, precision, recall, F1, ROC/AUC, cross-validation,
   imbalanced classes.
5. **Deployment** — Turning trained models into web services (Flask, Docker).
6. **Decision Trees & Ensemble Learning** — Random Forests, Gradient Boosting (XGBoost).
7. **Neural Networks & Deep Learning** — Fundamentals with TensorFlow/Keras.
8. **Serverless Deep Learning** — Serving models via AWS Lambda.
9. **Model Serving with Kubernetes** — TensorFlow Serving, scaling inference.
10. **Midterm & Capstone Projects** — End-to-end, deployed portfolio pieces.

> Module structure follows the official DataTalks.Club syllabus and may be refined as
> the 2026 cohort progresses.
